# Thinkora

**Think deeper. Build smarter.**

Thinkora is the home for tools that help people explore ideas, challenge assumptions, and make more thoughtful decisions.

## Thinkora Debate Room

Thinkora Debate Room brings together a simulated crowd of 300 perspectives — common people, CEOs, and specialist bots — to explore a question across three rounds. It also includes a Gemini-powered debate analysis and an AI chat assistant for follow-up questions.

### Design

- Deep midnight background for a focused, low-glare experience
- High-contrast text and clear panel separation
- Bright teal for affirmative actions and vivid coral for opposing views
- Responsive layout for desktop and mobile

### Project

The main interface is in `index.html`. The app also uses the `/api/chat` endpoint for its AI features.
